นโยบายความเป็นส่วนตัว

MUSICX ใช้ YouTube API Services เพื่อค้นหาและแสดงข้อมูลเพลง และเครื่องเล่น YouTube สำหรับเล่นวิดีโอ โดยไม่มีระบบสมัครสมาชิกของ MUSICX

ข้อมูลที่ใช้

คำค้นหาและคำขอข้อมูลเพลงจะถูกส่งผ่าน Cloudflare Workers ไปยัง YouTube Data API และอาจถูกแคชเพื่อช่วยลดคำขอซ้ำ เพลงโปรด Playlist ประวัติการฟัง สถิติการฟัง ท่อนโปรด ตำแหน่งการฟังค้าง และการตั้งค่าเครื่องเล่นถูกบันทึกใน LocalStorage บนเบราว์เซอร์ของคุณ ไม่ได้ซิงค์กับบัญชี MUSICX

เมื่อเข้าถึงรูปปกหรือเครื่องเล่น YouTube เบราว์เซอร์จะเชื่อมต่อกับบริการของ Google/YouTube ซึ่งอาจประมวลผลข้อมูลการเชื่อมต่อ การรับชม คุกกี้ และข้อมูลอื่นตามนโยบายของผู้ให้บริการ Cloudflare อาจประมวลผลข้อมูลคำขอเพื่อให้บริการและรักษาความปลอดภัย

ควบคุมข้อมูลของคุณ

คุณสามารถลบข้อมูลเพลงโปรด Playlist ประวัติ และการตั้งค่าของ MUSICX ผ่านปุ่มด้านล่างหรือการตั้งค่าเว็บไซต์ในเบราว์เซอร์ การลบนี้ไม่ลบข้อมูลที่ผู้ให้บริการภายนอกเก็บไว้

นโยบายของผู้ให้บริการ

นโยบายความเป็นส่วนตัว Google · ข้อกำหนด YouTube · นโยบาย Cloudflare

ผู้ใช้ MUSICX ตกลงอยู่ภายใต้ข้อกำหนดของ YouTube เมื่อใช้บริการ YouTube ผ่านเว็บไซต์นี้
